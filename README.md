# THE SAMURAI PHARMACY ITALY

Responsive bilingual (IT/EN) website, inspired by the navigational layout of BPFAM, with its own visual identity.

## Publish to GitHub Pages
1. Create a new public repository (e.g. `samurai-pharmacy-italy`).
2. Upload `index.html`, `style.css`, `app.js`, `manifest.webmanifest` and the entire `assets` folder, preserving paths.
3. Open Settings → Pages, choose Deploy from a branch → `main` → `/ (root)`, then Save.
4. Visit `https://YOURUSERNAME.github.io/samurai-pharmacy-italy/` after publishing.

## Edit
- Replace example contact descriptions in the Contacts section with your own verified official links.
- Add original authorized media to the Media section.
- Translate any new content in `app.js` in both `it` and `en` dictionaries.
- The uploaded logo remains **unaltered** at `assets/samurai-logo.jpeg`.

## Notes
- The age gate is a user confirmation, not identity verification.
- The demo doesn't collect personal details or accept orders.
- Draft legal notices are illustrative, not a substitute for a real privacy policy/terms.
- An installable full PWA with offline capabilities requires further icon sizing and a service worker; this starter includes a basic manifest only.
